Made in Godot 4.6.2 for the RETURN OF THE REALLY BAD IF game jam.
The game (except for the texts, of course) is licensed under the MIT license.

Texts (under "/texts/") obtained from Project Gutenberg. Said texts are in the public domain.

The only font used in this project is now W95FA, due to windows.ttf lacking many glyphs.
W95FA is licensed under the SIL OpenFont license.
You can find W95FA here: https://www.dafont.com/w95fa.font

Tools used:

	- Git
	- tetyys.com/SAPI4/

Texts used (all are in the public domain):
	- "Alice In Wonderland"
	- "Frankenstein; or, the modern Prometheus"
	- "The Adventures of Roderick Random"
